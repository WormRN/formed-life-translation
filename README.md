# formed-life-translation

An independent dynamic-equivalence translation of the New Testament designed for clear, natural English and free public use.

## Required entry point

Before continuing FLT translation or Engine 2.0 work, read [docs/START_HERE.md](docs/START_HERE.md) and then `config/engine_manifest.yaml`. These files define the current checkpoint, authority boundary, governing documents, and audit-retrieval procedure.
